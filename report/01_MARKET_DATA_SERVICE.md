## 1. Executive Brief (High-Level Summary)

The **Market Data Service** is the central nervous system of FinSight AI. It establishes an uncompromising single-source-of-truth pipeline for real-time asset pricing, historical OHLCV bars, and ticker metadata. By consolidating all data queries through a thread-safe singleton with high-performance caching, telemetry stamping, and a strict **Zero-Synthetic Guarantee**, it ensures that every metric, chart, and model across the platform operates on verified, consistent market data.

```

           │

```

## 3. Core Technical Features & Implementation

### 3.1 Thread-Safe In-Memory & SQLite TTL Caching
To protect external API rate limits and deliver sub-millisecond responses for hot tickers, `MarketDataService` implements a dual-tiered cache:
- **Quote Cache**: 30-second TTL during live market hours.
- **Historical Bar Cache**: 5-minute TTL for daily bars (1Y, 2Y, 5Y history).
- **Concurrency Protection**: Uses `threading.Lock()` to prevent race conditions during cache misses.

### 3.2 Telemetry & Provenance Stamping
Every JSON response generated by the data layer is stamped with provenance telemetry:
```json
{
  "ticker": "RELIANCE.NS",
  "price": 3012.45,
  "change_percent": 1.15,
  "high_24h": 3030.00,
  "low_24h": 2990.10,
  "volume_24h": 4521000,
  "data_source": "live",
  "fetched_at": "2026-09-06T15:20:00.000Z",
  "cache_hit": true,
  "provider": "yfinance"
}
```

### 3.3 Zero-Synthetic Guarantee in Live Mode
- If an asset ticker is invalid or external data feeds fail, the service returns an explicit HTTP 404/502 with actionable diagnostics.
- It **never** silently generates fake quotes, random walks, or synthetic placeholders when the user is in Live Mode.

---

## 4. API Specification

- `GET /api/quote/{ticker}`: Returns real-time quote, daily change, high/low range, and provenance metadata.
- `GET /api/history/{ticker}?period={1y|2y|5y}`: Returns historical OHLCV series.
- `GET /api/quotes?tickers=AAPL,MSFT,NVDA`: Batch quote endpoint for multi-asset synchronization.
